# IP 段归属查询接口文档

## 1. 接口简介

根据输入的 IPv4/IPv6 CIDR 网段，查询 IP 段起止地址、地理位置、运营商及是否属于 IDC 线路。

## 2. 接口信息

| 项目 | 内容 |
| --- | --- |
| 请求方式 | `POST` |
| 请求地址 | `http://43.138.198.101:8000/ip/api/apix` |
| Content-Type | `application/json` |

## 3. 请求参数

### Request Body

```json
{
  "apikey": "<YOUR_API_KEY>",
  "ranges": "175.12.22.0/24;240e:414:b06::/48"
}
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :---: | --- |
| `apikey` | `string` | 是 | API 访问密钥 |
| `ranges` | `string` | 是 | 待查询的 CIDR 网段；多个网段使用英文分号 `;` 分隔，支持 IPv4 和 IPv6 |

**CIDR 网段查询建议：** IPv4 建议使用 `/24`，IPv6 建议使用 `/48`。

## 4. 请求示例

```bash
curl -X POST \
  -H "Content-Type: application/json" \
  -d '{"apikey":"<YOUR_API_KEY>","ranges":"175.12.22.0/24;240e:414:b06::/48"}' \
  http://43.138.198.101:8000/ip/api/apix
```

## 5. 返回结果

```json
{
  "data": "175.12.22.0,175.12.22.255,湖南-张家界市,电信,否;240e:414:b06::,240e:414:b06:ffff:ffff:ffff:ffff:ffff,海南-琼海市,电信,是"
}
```

## 6. 返回字段说明

`data` 为字符串类型：

- 多条记录使用英文分号 `;` 分隔。
- 每条记录包含 5 个字段，字段之间使用英文逗号 `,` 分隔。

单条记录格式：

```text
开始IP,结束IP,地区,运营商,IDC线路
```

| 字段 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| 开始 IP | `string` | CIDR 网段的起始地址 | `175.12.22.0` |
| 结束 IP | `string` | CIDR 网段的结束地址 | `175.12.22.255` |
| 地区 | `string` | IP 所属省份及城市或区县 | `湖南-张家界市` |
| 运营商 | `string` | 网络运营商 | `电信` |
| IDC 线路 | `string` | 是否属于 IDC 线路 | `是` / `否` |

## 7. 返回示例

### 原始响应

```json
{
  "data": "175.12.22.0,175.12.22.255,湖南-张家界市,电信,否;240e:414:b06::,240e:414:b06:ffff:ffff:ffff:ffff:ffff,海南-琼海市,电信,是"
}
```

### 解析结果

| 开始 IP | 结束 IP | 地区 | 运营商 | IDC 线路 |
| --- | --- | --- | --- | :---: |
| `175.12.22.0` | `175.12.22.255` | 湖南-张家界市 | 电信 | 否 |
| `240e:414:b06::` | `240e:414:b06:ffff:ffff:ffff:ffff:ffff` | 海南-琼海市 | 电信 | 是 |

> 安全提示：请妥善保管 `apikey`，避免将真实密钥写入公开文档或代码仓库。
